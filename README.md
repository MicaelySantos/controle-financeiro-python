# 💰 Sistema de Controle Financeiro Pessoal em Python

Sistema de controle financeiro desenvolvido em Python, com o objetivo de praticar lógica de programação, organização de código e manipulação de dados.

O programa permite cadastrar receitas e despesas, consultar movimentações financeiras e acompanhar o saldo disponível por meio de um menu interativo no terminal.

## 🚀 Funcionalidades

- Cadastro de receitas.
- Cadastro de despesas.
- Listagem de movimentações financeiras.
- Consulta de saldo disponível.
- Relatório financeiro com total de receitas e despesas.
- Agrupamento de despesas por categoria.
- Armazenamento automático dos dados em arquivo JSON.
- Recuperação dos dados ao reiniciar o programa.

## 💻 Como executar

**1. Clone o repositório:**

```bash
git clone https://github.com/MicaelySantos/controle-financeiro-python.git
```

**2. Acesse a pasta:**

```bash
cd controle-financeiro-python
```

**3. Execute o programa:**

```bash
python main.py
```

É necessário ter o Python 3 instalado. O projeto utiliza apenas bibliotecas da própria linguagem.

## 💾 Armazenamento de dados

As movimentações são salvas automaticamente no arquivo `movimentacoes.json`.

O arquivo é criado durante a utilização do programa e permite recuperar as informações nas próximas execuções.
